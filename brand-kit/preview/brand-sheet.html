A handmade identity for a knitting & crochet companion. The mark is a little swatch of stockinette, cut like a linoblock; the wordmark is set in a sturdy woodtype-style serif.

A knit stitch is a V made of two loops. Stack the Vs in columns and you get stockinette, the fabric most sweaters are made of. The mark is a 2 × 3 swatch of it: cream stitches carved out of madder red.

Row 7 · Block & finish

Put it in the app

Full guide: brand-kit/IMPLEMENTATION.md.

  • New files are staged in brand-kit/repo/ at their final paths. Edits to the 11 existing files ship as one patch.
  • Checked against a copy of the repo: typecheck, lint, 45 tests and the web export all pass.
  • App icons and the splash only change in a new native build (EAS).
git checkout -b brand-kit
npx expo install react-native-svg expo-haptics
cp -R brand-kit/repo/. .
git rm -r assets/expo.icon
git apply brand-kit/knitwit-brand.patch
npm run typecheck && npm run lint && npm test
